# Student-Performance-Analysis
Student Performance Analysis Dashboard using power BI

Project Overview

This project analyzes student academic performance and attendance using Power BI.

Tools Used

- Microsoft Power BI
- Microsoft Excel

Dashboard Features

- Total Students
- Average Marks
- Average Attendance
- Highest and Lowest Marks
- Subject-wise Performance Analysis
- Individual Student Performance
- Attendance Analysis
- Student Performance Comparison

Dataset

The project uses an Excel dataset containing student details, attendance percentages, average marks and subject-wise marks.

Project Objective

To analyze student performance, identify academic trends and understand the relationship between attendance and marks.

Files Included

- Student_Performance_Data.xlsx
- Student_Performance_Dashboard.pbix
